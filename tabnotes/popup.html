TabNotes can't run on this page. Browser pages (chrome://, the new tab page, the Chrome Web Store) are not supported.

If this is a normal website that was open before TabNotes was installed or reloaded, refresh the page and try again.

Shortcuts: Alt+Shift+N new note, Alt+Shift+H hide/show. Notes are stored only on this device.
